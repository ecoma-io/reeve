# Bắt đầu

Hướng dẫn này hướng dẫn bạn cách thiết lập Reeve trong kho lưu trữ của mình.

## Điều kiện tiên quyết

- Một kho lưu trữ GitHub
- Một khóa nhà cung cấp hoặc điểm cuối không cần khóa

## Cài đặt

Thêm tệp quy trình làm việc vào kho lưu trữ của bạn và định cấu hình nhiệm vụ bạn cần.

## Lưu ý cho người dùng Việt Nam

Kho lưu trữ sử dụng `pnpm`. Cài đặt bằng:

```bash
corepack enable pnpm
```

Xem thêm tại [hướng dẫn pnpm tiếng Việt](https://pnpm.io/vi/).
